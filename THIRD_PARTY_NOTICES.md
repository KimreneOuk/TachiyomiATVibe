# Third-party asset notices

This file records provenance for model weights fetched or generated into `app/src/main/assets/models/` at build time by [scripts/fetch_models.py](scripts/fetch_models.py), and for fonts bundled by the Android app. The source repository does not commit standalone model files or offer model-only downloads. Build jobs package the fetched or converted files into APK assets. The manifest pins the byte size and full SHA-256 of each model; hashes identify exact bytes but do not establish redistribution permission. See [docs/MODEL_SOURCES.md](docs/MODEL_SOURCES.md) for upstream sources, conversion recipes, and license status. The root application license is in [LICENSE](LICENSE).

The PP-OCRv6 recognition model, configuration, detector model, and character dictionary come from pinned PaddleOCR sources. PaddleOCR and the upstream PP-OCRv6 model cards declare Apache-2.0.

The panel detector is derived from and attributed to [leoxs22/manga-panel-detector-yolo26n](https://huggingface.co/leoxs22/manga-panel-detector-yolo26n). The repository treats its YOLO26-derived weights as AGPL-3.0 under [Ultralytics' published model licensing terms](https://www.ultralytics.com/license), which state that trained YOLO models are AGPL-3.0 by default. The Hugging Face model card currently labels the checkpoint Apache-2.0; this notice records the AGPL determination used for the converted artifact. The converter, shared helper, and pinned dependencies provide corresponding conversion source. Build machines fetch the source checkpoint and convert it locally; this repository has no standalone model download, and the generated model is packaged into APK artifacts.

The Manga109 segmenter's redistribution status remains unresolved. The three font entries above record their identified names and available personal-use terms; redistribution permission for the bundled versions remains unverified pending a maintainer decision.
