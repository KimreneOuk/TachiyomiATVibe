# Delivery rule

This is an execution plan, not executed work. Start from `4de121bf7ed486e9f39b5a3f4f5c4288f439c8c8`. Each commit compiles both reader variants and passes the applicable deterministic gate before the next commit. A failure is diagnosed and repaired; it is not hidden by increasing sleeps, retrying until green or deleting a live boundary test.

The exact test retirement list is in the [test manifest](../test-manifest). File counts describe the final chosen plan, not a quota. Keep one integration owner for `TranslationPipeline`, `EngineLane`, reader queue and manager; independent agents can review or prepare disjoint changes, but cannot concurrently rewrite those shared seams.

Suggested PR grouping: C00–C02 purge; C03–C04 boundary/test seams; C05–C07 ownership and suspending bridges; C08–C10 queue cutover; C11 validation/docs. Each group can be reverted separately. Do not combine backend migration, persistence initialization or batch callback redesign with these PRs.

# Queue migration parity ledger

| Old behavior / test subject | New invariant |
| --- | --- |
| Manual preempts Auto lease | Same page promotion reuses operation/lease; distinct speculative work loses demand and drains. |
| Auto slot ready counters/window snapshots | Actual N+1 PageDisplayProjection readiness; no independent readiness decision or arbitrary N-ahead counter. |
| Auto registration/chapter owner version race | Reader-session generation rejects old resolver events and duplicate queue registration. |
| Auto provider call drain on stop | Request abandonment suppresses new work/publication; actual local/native completion and existing provider cancellation contract remain explicitly tested. |
| Manual outcome cache | Unified per-page typed outcomes, bounded retention and committed-display precedence. |
| Separate prepare/translate trace runs | One page operation trace with explicit stage boundaries and exactly one terminal; native and provider occupancy still measured independently. |
| Session switch/batch owner handoff | Reader request never steals BATCH lease; workflow admission/cancellation remains ordered. |
| Source ready and page resolver invalidation | One resolver wakes deferred work for the current reader generation; stale stream factory cannot open after teardown. |
