# Outcome

The connected OpenVINO validation completed for CPU and GPU on the available
host. It is a real stage chain: encoder output feeds `decoder_init`, init K/V
feeds `decoder_step`, and each greedy step writes returned self K/V at
`position_id - 1` before the next step. The raw evidence is in
[`openvino_chained.json`](../results/openvino_chained.json), generated by
[`test_openvino_chained.py`](../test_openvino_chained.py).

This remains a host experiment on synthetic tensors. It does **not** justify an
Android acceleration claim.

## Run contract

- OpenVINO `2026.1.0-21367-63e31528c62-releases/2026/1`.
- Pristine ONNX Runtime CPU reference (`CPUExecutionProvider`, ORT `1.24.1`).
- Two deterministic `[1,3,224,224]` fixtures, eight decoder steps, one warmup,
  and three timed iterations per fixture.
- Comparison records token equality, every compared position's logits, and
  max/mean absolute logit differences. The strict logit gate is max absolute
  `5e-3` and mean absolute `1e-4`.

## Results

| Requested path | Actual execution | Token parity | Logit result | Connected median (fixture 0 / 1) |
|---|---|---:|---:|---:|
| CPU | encoder/init/step all `CPU` | 2/2 | pass; max abs `5.15e-5` / `8.39e-5` | `71.03 ms` / `71.33 ms` |
| GPU | encoder/init/step all `GPU.0` | 2/2 | **fails strict gate**; max abs `0.1302` / `0.1534` | `189.24 ms` / `360.50 ms` |
| AUTO | all stages `(CPU)` | 2/2 | same CPU-fallback result as the routed CPU path; not an accelerator | `1564.60 ms` / `1622.17 ms` |
| NPU | compile blocked | not run | **BLOCKED**: `[NPU_VCL] Unrecognized device ID!` | not run |

GPU tokens matched in both fixtures, but logits differed materially from the
pristine ORT CPU reference. Because the experiment's required numerical gate is
not met, and the measured connected GPU path was slower than CPU on these
fixtures, no GPU speedup is claimed. The GPU result needs a deliberate
cross-runtime tolerance/accuracy decision and broader real-crop validation
before it can be considered further.

`AUTO` is explicitly labeled CPU fallback from compiled execution-device
properties; its successful inference is not evidence of accelerator use.

## Scope and remaining blockers

- The chain and cache mutation are now validated, correcting the independent
  random stage-call flaw in the earlier OpenVINO probe.
- Inputs are synthetic and do not measure OCR quality, Android preprocessing,
  Android memory, thermal behavior, or the shipped Kotlin protocol.
- NPU was not available on this host; the exact plugin compile error is retained
  in the raw JSON. No NPU speedup is claimed.
- The result is observational evidence only; app code and model assets were not
  modified.
