# Security Policy

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/KimreneOuk/TachiyomiATVibe/security/advisories/new) for sensitive reports when available. For non-sensitive security issues, open an issue labeled `security`. Do not post exploit details, API keys, or credential-bearing logs in public issues.

## Supported versions

The project currently distributes source only and has no published release channels or separately supported binary versions. Include the source commit or CI build details when reporting an issue.

## Provider credentials

User-supplied provider API keys are stored locally on the device only. Never include keys, tokens, or credential-bearing logs in bug reports or pull requests.
