# Plans

## New work

Create a dated folder under `Plan/active/`:

```text
Plan/active/<YYYY-MM-DD>-<short-topic>/
```

Start with `brief.md`. Add `investigation.md`, `design.md`, `checkpoints.md`,
and `handoff.md` only when the task needs them. Follow
[`docs/project_context/knowledge_base.md`](../docs/project_context/knowledge_base.md)
for authority and document-routing rules.

## Existing plans

The flat files in this directory are retained as historical and currently
active project records. Do not reorganize them automatically; link to them
from a new task folder when continuing related work.
